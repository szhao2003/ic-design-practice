# 第二阶段：判分与学习状态模型

## 实现范围

- `grading.ts`：单选、多选、判断与数值自动判分；非法输入返回具体错误，不创建正式作答。
- `practice.ts`：独立轮次、草稿、正式提交、辅助揭示、线上独立作答及纸笔声明、人工自评。提交后答案锁定，重复操作不增加事件。
- `review.ts`：不可变事件去重、冲突检查、按时间重建复习状态，自动题统计与人工自评独立。
- `snapshots.ts`：题面、选项、参考解及来源信息深拷贝，稳定的题号与版本键；不读取新版题库重判历史。
- `backup-merge.ts`：内存中的备份合并预检与规划；同 ID 异内容、同版本异题面、同时间不同笔记及会话歧义均拒绝。较新的删除标记保留，不复活已删除内容。
- `mock-session.ts`：模拟卷核心状态合同；创建时保留题目快照，保存期限检查，幂等交卷，未答单列、人工题待自评、活动卷不可揭示答案。

## 行为约定

数值输入使用 `{ raw, unit? }`，单位独立选择。仅在题目有显式 `defaultUnit` 时允许缺省；纯数题无需单位。十进制与科学计数法完整解析，拒绝 NaN、Infinity、额外字符、未知单位及换算溢出/下溢。

计算在标准单位中进行，绝对/相对容差取最大值并包含边界。区间端点比较处理浮点减法边界，不给零容差增加隐式误差。

人工题必须通过“保存独立作答并查看参考答案”动作或纸笔声明固定独立性。已有草稿但直接揭示仍算辅助学习。本轮辅助学习的 good 记录原始请求，但有效等级最高 partial，不增加独立掌握。揭示事件与正式自评是不同事件。

复习采用本地日历加天：1/3/7/14/30/30；partial、again、错误、辅助揭示清零连续次数。partial 和辅助揭示不清除旧错题，独立正确/good 才清除。普通自动题正确率只使用正式非空自动提交；辅助揭示和人工自评不进入分母。

已完成的模拟卷只保留首次结算结果。恢复过期活动卷时使用 deadline 时间和已保存答案，同一 session/question 形成稳定事件 ID。未答自动题计入考试分母、计零分，不形成普通提交事件。已答人工题只保存待自评轮次。

非法格式的已保存草稿单列错误、考试计零分且不产生普通作答事件，不能让超时交卷卡住；原始作答仍保留供回顾。

备份合并模型要求调用方先完成输入 schema 校验。它返回完整计划或冲突列表，不做数据库修改。历史顺序按时间、揭示优先级及稳定事件 ID 确定；写入层应保留可靠时间戳与轮次 ID。

## 验证与边界

本阶段新增判分、轮次、自评、复习、快照、备份预检及模拟状态测试；包括 America/Los_Angeles 春季 23 小时、秋季 25 小时情况下本地钟点保持。

本地验证：7 个测试文件、84 项测试通过，严格类型检查、生产构建和题库结构校验通过。正式题库仍为 0，道题数量与内容审核未在本阶段开展。

尚未接入网页或 IndexedDB，未实现导入文件 schema/迁移、数据库事务回滚或跨标签页写入协调。因此这里通过的是纯模型测试，不能视为浏览器持久化、实际备份恢复、考试全站防剧透或正式上线验收。

下一阶段把单题流程接入 IndexedDB，保证状态、事件、快照、派生进度在同一事务提交，并以真实存储故障测试验证回滚。
