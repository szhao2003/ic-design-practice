# 第三阶段：可使用的单题练习与记录

## 当前可用流程

- 题库/专题选题 → 独立作答 → 自动判分或揭示后自评 → 完整解析。
- 草稿即时入库、刷新恢复、重做开启新轮次、保留历次原始答案与题面版本。
- 自动保存个人笔记及四类纠错标记，收藏可取消，纠错清单可以单独导出。
- 错题、到期复习、已解决错题、收藏、笔记分栏；从错题列表开始独立复习会先创建空白轮次。
- 首页显示真实题量、独立练习题数、自动正确率分子/分母、到期数及继续未完成题目。完整专题目录单独保留。
- JSON 导出 → 文件校验 → 合并/覆盖预览 → 用户确认 → 同事务恢复；清空需再次输入确认文字。

## 数据与一致性

使用 IndexedDB，独立保存事件、题面快照、个人记录/草稿、模拟会话、派生复习状态和修订号。每次单题提交在同一事务中写入相关数据；中途写入故障会整体回滚，不留下半条记录。

同一题的草稿带轮次 ID 与修订号。其他标签页修改后，旧页面不能覆盖新答案，需重新载入。页面之间通过更新通知和重新聚焦刷新统计。

备份 schemaVersion 为 1，是首个实际学习记录格式。损坏、未知、旧版或未来版本若没有安全迁移路径就明确拒绝。导入会检查快照引用、自动评分与旧答案是否一致、辅助揭示和独立性约束、草稿状态能否回放、记录冲突、模拟会话一致性。预检后若有新数据写入，旧计划失效，要求重新预检。

已超时的备份模拟会话在导入时按原截止时间结算，不重复产生作答。模拟页面仍未开放，本阶段只交付其数据恢复能力。

删除笔记和取消收藏保留明确的空值/删除记录，旧备份不能复活较新的删除。未知题历史仍保留快照，可查看并单题重练，但不进入当前可练题统计。

## 自动验证

8 个测试文件、102 项测试通过；包含 IndexedDB API 的内存实现测试，验证关闭连接恢复、重复提交、重做版本、多连接竞争、提交故障回滚、导入中断回滚、导入预览过期、备份往返、反复合并不翻倍、未知题保留、非法备份及超时会话恢复。

这类测试模拟数据库 API，不替代浏览器或真实磁盘故障测试。

## 浏览器验证

在单独本地预览来源中创建验收数据，未向线上写入个人记录：

1. CDC 单选提交 A，显示错误及 A/B/C/D 的逐项原因；错题列表出现该题。
2. 保存笔记并收藏，刷新后答案、记录、笔记、收藏均保持。
3. 从错题列表开始独立复习，输入为空、当前参考答案隐藏；答 B 后保留两条历史，错题解除。
4. STA 输入 1500 并选 ps，刷新后草稿与单位保持，提交正确；另一次输入非法值后能直接改正。
5. CDC 简答直接揭示后点 good，有效等级为 partial，不增加自动准确率或独立练习题数。
6. 真实下载 JSON，通过文件选择导入、校验、确认合并；5 条事件仍为 5 条，自动正确率保持 2/3，无重复计数。
7. 窄屏请求 375px，工具实际内容视口报告 360px，题面和数字输入无横向溢出；浏览器无错误日志。
