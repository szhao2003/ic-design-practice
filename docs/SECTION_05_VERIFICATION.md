# 第五阶段：模拟考试

版本 0.4.0，完成模拟卷从创建、作答、自动保存、交卷到复盘的网页与存储流程。题库仍为 50 道，没有修改题目内容。

## 使用行为

- 按一个或多个核心专题随机组卷，默认全部；支持 1–100 题、1–240 分钟或不限时。可用题不足时显示实际题量；同卷不重复。
- 固定题目版本与题序，保存答案、开始时间、截止时间和当前位置。切题无需先答完，答题卡区分已填写和未填写，已填写不表示格式有效或答案正确。
- 交卷前不渲染答案、解析、提示、来源跳转、历史和笔记；其他站内路径会返回当前活动卷，已打开页面通过跨标签消息刷新状态。这里只提供学习流程防剧透，不构成监考或安全隔离。
- 限时离开页面继续计算；截止后锁定输入并按最后持久化答案结算；重新打开或导入过期卷也恢复结算。页面关闭期间不会后台运行，结果在再次打开时按原截止时间恢复。
- 主动交卷先显示确认摘要。交卷结果、自动作答事件和复习统计同一事务保存，失败全部回滚。重复交卷不重复创建事件。
- 自动题每题 1 分，未答及格式无效计考试 0 分、计入本卷分母，但不形成普通提交事件。人工题只对交卷前已保存的独立文字/代码进入自评；空白人工题不创建掌握记录。
- 自评按交卷时快照与答案生成稳定事件，原卷结果不变；重复自评保留首次结果。

## 兼容与失败处理

数据库仍为 IndexedDB v2；schemaVersion=1。模拟卷新增可选 currentIndex，缺省位置按 0 恢复，旧备份可导入。自评记录由原模拟卷关联并验证，不能在导入时偷换交卷答案。新版备份应由新版应用读取。

答案与交卷采用整卷内容比较防止其他标签页覆盖。保存失败时显示错误、锁定继续操作并要求重新载入；不会把未保存输入标记为成功。个人考试、笔记、备份和测试截图不提交仓库。

## 验证

自动化覆盖组卷边界、答案与位置恢复、交卷及保存失败回滚、未答/非法输入计分、重复交卷、人工自评与备份恢复、跨连接冲突、截止时刻拒绝晚到答案、关闭后到期恢复、过期卷导入及直接路径保护。浏览器验收覆盖题量不足、刷新恢复、隐藏解析入口、统一结果、人工自评和真实倒计时恢复。本地 13 个测试文件、163 项测试通过，类型检查、50 题正式内容校验和生产构建通过。实际浏览器验证了不限时 7 题卷的刷新/位置恢复、直接路径保护、统一交卷、人工自评；1 分钟限时卷关闭后重新打开按截止时间恢复为未答 0 分；导出并合并导入包含 2 个模拟会话和人工自评的备份后仍为 3 条事件，未重复计数。390 px 视口下检查组卷与作答页，无横向溢出。浏览器测试数据和截图未提交，发布状态以当前 Actions 为准。
