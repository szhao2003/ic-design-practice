# 学习进度详情

版本 0.5.0 完成学习进度页，并从首页提供直接入口。此阶段不修改题库、数据库结构、备份 schema 或已有学习记录。全站正式 V1 综合验收仍待下一节。

## 统计口径

- 分母为当前安装且已审核的不同题目 ID；专题归属使用当前题库分类。旧版本作答按当时保存的判分事件计算，不用新答案重判。
- 独立练习覆盖按题去重：有效自动提交或独立人工自评至少一次；草稿、直接揭示、辅助自评不增加覆盖。覆盖不是掌握率，未练也不等于不会。
- 自动正确率按所有有效提交次数加权计算，不平均专题百分比。考试未答或格式无效没有普通提交事件，不进入这个分母；考试得分另行展示。
- 独立人工自评与辅助自评分开累计。最近独立掌握仅统计该题最新事件为独立 good；之后的揭示会清除此当前标记，但保留过去覆盖与历史次数。
- 到期复习包含 nextReviewAt 等于当前时刻的边界；未解决错题沿用事件派生状态。待巩固包括最近答错、partial、again 或辅助学习，未做题不列为错题。
- 已移除或未审核题历史仍保留在备份中，但不污染当前题库统计。没有题目的专题单列为待扩充，不显示百分比。

## 页面内容

累计统计、七核心专题覆盖条及各专题的自动/人工/复习指标；待扩充专题目录；按专题筛选的待巩固知识点、前 10 道题、真实笔记摘要和最近 10/50 条活动；最近三份已交卷模拟考试入口。记录保留题面版本和时间，明确区分自动判分、独立自评与辅助学习。

下方记录筛选不改变上方累计指标，页面明确说明。到期状态每分钟刷新，浏览器重新取得焦点后由现有数据层重新读取。考试进行时沿用已有全站路径保护，不能从本页提前查看历史或笔记。

## 验证

新增 9 项统计测试：零记录与未审核题、按次数加权、覆盖去重、草稿/揭示排除、独立与辅助自评、最新揭示后的状态、旧版本与移除题、重复/冲突事件、到期边界及错题解决、模拟未答和人工待自评。

浏览器在独立本地来源验证零记录、实际错误提交、独立 partial 自评、辅助揭示及笔记保存，结果为独立覆盖 2/50、自动 0/1、独立人工自评 1、未解决错题 1；辅助揭示未增加分母。按专题过滤能隔离对应活动与笔记；刷新后统计不变。390 px 视口检查无横向溢出。测试数据和截图不提交公开仓库。

本地全部 14 个测试文件、172 项测试通过；正式 50 题结构及分布校验、类型检查与生产构建通过。发布结果以对应 Actions 为准。
