# 导航简化与图片附件

2026-11-25，1.27.0。题库保持234题，未改题目内容或清理用户记录。

## 用户可见改动

- 知识专题移除“核心专题练习路径”和“综合题分步引导”两个目录。保留15专题、原学习顺序建议和题目内按需引导。旧路径练习会话与历史继续可打开，没有删除数据库记录。
- 导航只保留“题库”，移除“专项练习”。原`/practice`入口重定向到`/questions`并保留查询条件；单题`/practice/:id`和连续练习地址不变，已有链接可用。
- 普通及连续练习的简答、RTL、波形作答支持图片，也可只提交图片后人工自评；个人笔记支持图片。模拟考试的独立答题界面本版仍使用原文本输入。
- 选择JPG/PNG/WebP或在输入区域粘贴截图，显示缩略图、原文件名，可放大预览及在提交前移除；预览使用原生模态对话框，可按Esc关闭。
- 本机解码后等比压缩为JPG，最长边1600像素，每张最多1MB，每处最多6张。原图上限15MB；透明区域转白底；不保留原文件元数据。图片不上传服务器，也不执行OCR或图片判分。

## 保存与备份

作答图片是轮次草稿的一部分，自评或辅助揭示后锁定，历史事件保存独立副本；重做产生不含旧图片的新草稿。旧作答与笔记图片受原学习门禁保护，未独立完成前隐藏，主动揭示仍按辅助学习计数。

笔记图片存入独立noteImages记录，避免改变旧文字笔记结构；只有图片的题目也出现在“错题与复习→笔记”。移除笔记图片保留删除记录用于合并；不会删除历次作答图片。

图片随完整JSON备份导出，导入时验证类型、内嵌数据格式/签名、单图长度、数量和ID唯一性；旧无图片备份仍可读取。保留schemaVersion=1及既有可选字段兼容方式，旧版应用可能拒绝含新字段的备份，应使用当前版本恢复。

取消旧导入界面25MB限制，以免本站导出的含图备份无法重新导入；含图备份较大，依赖设备内存完成读取与预检。没有云同步；本地配额不足会回滚事务并提示导出备份、整理图片后重试，不显示保存成功。
