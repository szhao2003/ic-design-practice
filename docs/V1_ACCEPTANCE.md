# V1 功能与回归验收

版本 1.0.0，核对日期 2026-11-23。网站按现有本地优先方案交付，62 道审核题覆盖七核心专题，另八个专题明确列为待扩充。以下记录实际执行范围，不声称完成未执行的浏览器或 HDL 仿真测试。

## 自动化与内容

- 16 个测试文件、184 项测试：判分、单位/容差、复习、历史版本、筛选、来源分类、连续练习、模拟状态、IndexedDB 事务/冲突/回滚、导入恢复、学习统计、内容数学模型及 Markdown 渲染。
- 正式题库门槛检查通过：62 道，专题数量 9/12/8/8/8/11/6；题型单选 13、多选 9、判断 1、数值 17、简答 8、RTL 7、波形 7。
- 原创 44，公开笔经考点改编 6，练习汇编考点改编 12；无可核实原题摘录或原题转述。新增汇编不继承未经独立支持的公司、届别归因；原有 50 题完整记录与版本不变。
- 类型检查、生产构建、干净依赖安装检查及 CI 正式内容门槛均执行；部署结果由对应 Actions 和线上构建验证。

## 本次浏览器回归

使用内置 Chromium 浏览器及独立本地来源测试，不触碰公开站点的个人数据。

| 流程 | 结果与依据 |
|---|---|
| 新题列表/搜索/来源 | 搜索 YHCHub 匹配 12 道；列表和来源详情标明公开资料考点改编、非原题、C 级及原汇编题号；checked 仅表示汇编链接/考点已核对 |
| 数值/单选/多选/判断 | 定点位宽 8、符号扩展编码 1005、敏感列表选项 A、Gray 跳步集合 A/B/D 及原判断题 false 均得到预期反馈 |
| RTL/长代码 | 新人口计数器显示完整接口、代码、位宽说明和自评要点，不显示自动代码正确结论 |
| 旧版解析 | 原卡诺图生成一个真实表格，八行真值可读；相同参考解与解析只显示一次；不修改旧题快照 |
| 复制边界 | 新题提交前复制包含题面、不包含数值答案；提交后勾选附答案才包含答案 |
| 模拟卷保护 | 62 道题进入组卷范围；活动卷直接访问学习进度会返回考试，答案解析不可见；未答交卷本卷 0/1，普通提交不增加 |
| 空库备份恢复 | 从 127.0.0.1 来源导出，在 localhost 独立空记录来源预检并合并导入；恢复 5 条事件、5 份题面、5 份草稿、1 个模拟会话；进度为 3/62、自动 3/3，模拟未答 0/1 独立保留 |
| 手机主导航 | 390 px 视口依次访问首页、专题、题库、专项练习、复习、模拟、进度、设置；各页内容宽度不超出自身可视宽度 |
| 手机表格 | 旧真值表真实显示一个 table，内容宽度不超出可视宽度 |

先前阶段还实际验证了限时卷关闭后按原截止时间恢复、人工自评、同一备份重复合并不增加事件；详见阶段 3–5 与进度报告。当前回归没有逐一重跑所有历史操作，重复计数、损坏备份、事务失败和版本冲突等边界由自动化持续覆盖。

## 交付与边界

- 主导航的八个页面均有实际功能；无开发占位入口。记录只在当前浏览器来源保存，支持完整 JSON 备份，数据库仍为 v2、schemaVersion=1。
- CI 使用 --release 内容校验，主分支检查通过才发布；PR 不发布。GitHub Pages 继续采用仓库 base 和 HashRouter。
- 测试记录、备份、截图及内部交接材料不提交公开仓库；依赖许可信息保留，无工具宣传或项目作者署名。
- 仅对当前执行环境作验证：未声称 Safari/Firefox 独立实测、实际 HDL 仿真/综合、在线监考、账号云同步或不丢数据保证。人工题仍需对照参考答案自评。
- 题目可继续按稳定 ID/版本约定扩充，已有历史不重判；新版本备份使用新版本网站导入。
